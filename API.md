# API notes (current implementation)

Base path: `/api/v1`

| Method | Route | Auth | Purpose |
|---|---|---|---|
| GET | `/health` | No | Development health response |
| POST | `/auth/login` | No | Username/password login; returns bearer token |
| GET | `/customers?q=&offset=&limit=` | Bearer | List active customers |
| POST | `/customers` | Bearer | Create customer |
| GET | `/customers/{id}` | Bearer | Read customer |
| PATCH | `/customers/{id}` | Bearer | Update customer |
| DELETE | `/customers/{id}` | Bearer | Soft archive customer |
| GET | `/products?offset=&limit=` | Bearer | List products |
| POST | `/products` | Bearer | Create product |

OpenAPI is generated by FastAPI at `/docs`. These routes are a partial subset of the required API. Do not infer that missing route groups are implemented.


## Bale Bot (polling)
Incoming updates are processed by a background long-polling task when `BALE_BOT_TOKEN`, `BALE_ADMIN_CHAT_ID`, and `BALE_POLLING_ENABLED=true` are configured. The bot registers subscribers, welcomes them, routes support-ticket submissions to the configured administrator, and exposes admin-only menu actions. See `BALE_BOT_FA.md`.
